Open terminal in the current directory and run the command 'make'.

Run the Python code 'MainScatWidth.py' (Adjust the value of 'ratio'). This will compute the scattered electric field.

Run 'RCS_LBM.py' to compute the scattering widths.

Run 'RCS_Exact.py' to compute the analytical scattering widths.

Run 'RCS_Plot_{}.py' to plot the scattering widths (Rayleigh, Mie and GO).
